# Project Name

Developer Names: Jacob Brodersen, Nehan Munir, Joshua Engel, Amos Edeaghe, Allen Tong

Date of project start: September 17, 2026

This project is a game that requires the player to find special formations in an 8 x 8 x 8 magic cube.

The folders and files for this project are as follows:

* docs - Documentation for the project
* refs - Reference material used for the project, including papers
* src - Source code
* test - Test cases
* pdfs - PDF versions of the documentation for the project
* site - Configuration files for the project website

The documentation for this project is updated on the project's [GitHub page](https://jacob-mb.github.io/magic-8/).
