\subsection{Background}

A most perfect magic cube is a cube where each voxel's value is a distinct number from 1 to n\textasciicircum{}3 and all rows, columns, pillars, 2-dimensional diagonals, 3-dimensional diagonals (triagonals), and broken space diagonals in the cube sum to the same number, also called the magic constant. The order-eight cube is the smallest order most perfect magic cube. Using octal within this order-8 magic cube showcases the magic properties of the cube with the above prescribed lines summing to 4004, half lines summing to 2002, and the complementary numbers (+4 4 4 for the x y z coordinates from a given voxel) summing to 1001 (all in octal).

Our project, Magic 8, is a web-based application that serves as a recreational mathematics game as well as an educational tool for octal addition and subtraction. In this proposed game, players start with one voxel (number) in a most perfect magic cube visible while all other voxels remain hidden. The player must then complete tasks related to finding the voxels belonging to lines that sum to the magic constant. Each round of the game includes eight tasks that increase in difficulty as the player progresses.

\subsection{Hazard Definition}

A hazard is defined as a system state that if combined with a specific environmental condition, can cause harm/damage. Hazards can result from software defects or incorrectly defined system behavior. These hazards can be categorized as health, data, education, and usability hazards.
